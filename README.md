# usz_artemis_preprocessing

Python package for the TB adaption workflow.

## Layout

- `src/usz_artemis_preprocessing/`: application package with GUI, DICOM handling, registration, export, and utilities
- `tests/`: automated tests
- `tools/`: support scripts such as the PyInstaller build helper
- `test_data/`: local data for manual or automated testing
- `build/`, `dist/`: generated artifacts
